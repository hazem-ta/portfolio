# Hazem Ahmed — Portfolio

Recruiter-focused personal portfolio for Hazem Ahmed, a software developer based in Cairo.

**Live site:** [hazem-ta.github.io/portfolio](https://hazem-ta.github.io/portfolio/)

## Highlights

- Responsive, accessible single-page design
- Selected software projects with technical context
- Professional experience, skills, education, and contact details
- SEO, Open Graph, structured data, sitemap, and reduced-motion support
- No framework or build step required

## Local preview

Serve the repository with any static HTTP server. For example:

```bash
npx serve .
```

Then open the URL shown in the terminal.
